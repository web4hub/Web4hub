## 🧭 About

**Web4hub** is an evolving technology ecosystem exploring the convergence of Web4, artificial intelligence, blockchain, and software engineering.

The repository acts as a home for experiments, documentation, developer infrastructure, intelligent systems, decentralized technologies, and next-generation applications.

## 🚀 Core domains

| Domain | Focus |
|---|---|
| 🌐 Web4 | Applications, identity, protocols, persistent digital experiences |
| 🤖 AI | LLMs, agents, local AI, knowledge systems, AI tooling |
| ⛓️ Blockchain | Cryptography, trust, wallets, ledgers, distributed systems |
| 🛠️ Software | SDKs, APIs, compilers, runtimes, cloud and automation |
