# Web4hub Ecosystem

Web4hub organizes related projects around shared concepts rather than forcing every project into one runtime.

## Capability map

### Web4
- Web4 application platform
- Web4 publishing and services
- Web4.0 research and experimentation

### AI
- LMLM and AI runtime work
- AI plugins and integrations
- OmniSkel-AI research/application systems
- Prompt and knowledge tooling

### Engineering and research
- Software architecture
- Compiler and language engineering
- Mathematical and dimensional research

## Evolution path

**Identity → Protocols → Infrastructure → Applications → Ecosystem**

Projects can enter at any layer while remaining compatible with shared standards.
